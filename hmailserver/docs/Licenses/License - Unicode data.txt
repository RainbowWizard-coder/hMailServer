The Unicode Character Database files that UTS 46 is done from, vendored at
hmailserver/source/Server/Common/Idna/ucd (IdnaMappingTable.txt, IdnaTestV2.txt,
UnicodeData.txt, CompositionExclusions.txt, DerivedJoiningType.txt and
DerivedBidiClass.txt, Unicode 18.0.0), and the tables build/generate-idna-tables.py
makes of them, IdnaTables.cpp and IdnaTestData.cpp beside it, which are compiled
into the server on Windows and Linux: the mapping, normalisation, bidi and joiner
data a browser reads a link's host with. The file below is a verbatim copy of
ucd/unicode.LICENSE, which is kept beside the data, and is here so that this
directory is a complete list of the third-party terms this repository carries.
