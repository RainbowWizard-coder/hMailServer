License list
============

The original hMailServer's list of the third-party components it carried and what
each one's licence asks: the table Martin Knafve kept as an OpenDocument
spreadsheet, `License list.ods` (made in July 2010 and last saved on 12 September
2010), written out here cell for cell since the spreadsheet left the tree on
23 October 2026. Its first sheet held this table and its other two were empty. The
spreadsheet is in the git history from `fe45f43c3`.

| Component | License file | OSI approved | AGPL compatible? | Requires attribution | Requires URI | Include in overall license |
|---|---|---|---|---|---|---|
| Boost | License - Boost.rtf | Yes | Yes | No | No | No |
| FatCowIcons | License - Fat Cow Icons.rtf | No | No | Yes | Yes | Yes |
| Microsoft SQL Server Compact | License - Microsoft SQL Server Compact Edition.rtf | No | No | No | No | Yes |
| MIME Message encoder analyzer | License - MIME Message encoder analyzer.rtf | No | Yes | No | No | No |
| OpenSSL | License – OpenSSL.rtf | No | No | Yes | No | Yes |
| PostgreSQL interface | License - PostgreSQL interface.rtf | No | Yes | No | No | Yes |
| RMSPF | License – RMSPF.rtf | No | Yes | No | No | No |
| String library | License – String library.rtf | No | Yes | No | No | No |
| Zlib | License – Zlib.rtf | Yes | Yes | No | No | No |
| InfoZip | License - InfoZip.rtf | No | No | Yes | No | Yes |

The table is as the spreadsheet gave it, the en dash in four of its file names
among them, and its answers are the original's of 2010: the tree keeps them as they
were and does not keep them up to date. This folder's file names have a hyphen, and
zlib's is `License - ZLib.rtf`; `License - RMSPF.rtf` left on 15 September 2026
with the SPF library it covered, and the folder holds no `License - InfoZip.rtf`.
The folder's notices of 7-Zip, the MariaDB client, QuickJS, the RFC 7208 test
suite, Unicode's data and the HTML standard's named character references are not
in the table. Which licence covers what a release carries today is in the
texts of this folder, [SourceTarball.md](../SourceTarball.md) and
[ThirdPartyBinaries.md](../ThirdPartyBinaries.md).
