The HTML standard's list of named character references, vendored at
hmailserver/source/Server/Common/AntiSpam/whatwg/entities.json as
html.spec.whatwg.org serves it, and the table build/generate-html-references.py
makes of it, HtmlReferencesData.cpp, which is compiled into the server on
Windows and Linux: every named reference HTML defines, which the SURBL test and
the sender lists' URL entries read an HTML part's links with, as a browser does.
The file below is a verbatim copy of whatwg/entities.LICENSE, which is kept
beside the list, and is here so that this directory is a complete list of the
third-party terms this repository carries.
