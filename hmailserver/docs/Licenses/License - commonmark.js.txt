commonmark.js, John MacFarlane's JavaScript implementation of CommonMark
(https://github.com/commonmark/commonmark.js), one of CommonMark's two
reference implementations. build/check-release-chain.py, a check of the
project's CI that reads the project's Markdown documents for the commands they
give, holds a Python port of parts of its release 0.31.2: the regular
expressions of lib/blocks.js and lib/inlines.js that its MARKDOWN_* constants
are, character for character but for \d written [0-9] and $ written \Z
(reThematicBreak, reMaybeSpecial, reCodeFence, reClosingCodeFence,
reATXHeadingMarker, reSetextHeadingLine, reBulletListMarker,
reOrderedListMarker, reHtmlBlockOpen and reHtmlBlockClose, reLinkLabel,
reLinkDestinationBraces, reLinkTitle, reSpnl, reSpaceAtEndOfLine and
ESCAPABLE); its markdown_reference, which reads a link reference definition
step by step as inlines.js's parseReference and parseLinkDestination do; and
its markdown_command_ends, which follows blocks.js's incorporateLine and
blockStarts: the open blocks' continuation in order, then the block starts in
their order. The rest of the file is the maintainers'. The check is compiled
into no program and no package carries it; the source tarball and the Debian
source package carry it with the rest of build/. The release was read from its
npm tarball, commonmark-0.31.2.tgz, whose sha512 equals the registry's
integrity value
(sha512-2fRLTyb9r/2835k5cwcAwOj0DEc44FARnMp5veGsJ+mEAZdi52sNopLu07ZyElQUz058H43whzlERDIaaSw4rg==).
