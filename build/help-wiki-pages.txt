# The project's wiki, page by page, and the documents each page was made from: what the help panes'
# "Open on the wiki" opens. The wiki's pages have names of their own - Backup-and-Restore, not
# Backup - so the link is the HelpWikiBaseUrl setting with the page's name, never the document's,
# and a document no page was made from has no link at all.
#
# build/generate-help-pages.py reads this file into the server (HelpPagesData.cpp, which
# GET /api/v1/help answers to the Control Deck and the webmail as each page's wiki_page) and into
# the Control Panel (Services/HelpWikiPages.g.cs); build/check-help-map.py holds it to the documents
# in every pipeline and, given the wiki's repository with --wiki, to the wiki itself. docs/Help.md,
# "The wiki link", says how the three panes use it.
#
# One line for every page of the wiki - every .md file at the top of the wiki's repository - and
# after the page's name, the documents (hmailserver/docs) it was made from, or none:
#   * a page that is a document's copy - its opening says "Source of truth: hmailserver/docs/X.md,
#     kept in the repository and copied here", or that it is "the wiki copy of" it;
#   * a page written from documents - "Written ... from hmailserver/docs/X.md, Y.md and Z.md", or,
#     for The Webmail, from "the operator documents under hmailserver/docs that each section links":
#     the documents its sections link;
#   * the manual's chapter brought up against a document (Backup and Restore, against Backup.md).
# A document a page names for a part of its own subject, or points at, is not the page's: RemoteDomains.md
# on Encryption for People (its gateway encryption), ActiveActive.md on the High Availability Runbook,
# ContinuousIntegration.md, TestLab.md, Webhooks.md and ControlPanelDesign.md where they are pointed at.
# A document two pages were made from is the page's that is its copy, then the one about its own
# subject: Upgrading.md is the Upgrading guide's copy, not the chapter Upgrading hMailServer's;
# UpdateFeed.md is The Update Feed's; BounceSuppression.md is Outbound Shaping's, not Mailing Lists';
# ConfidentialMessages.md and PersonalData.md are the pages' written from them by name, which The
# Webmail links as well. A document appears once; README.md and DeckParity.md, which the help does not
# carry, never.
#
# When the wiki gains, loses or renames a page, or a page is made from another document, change this
# file in the same change and run, with a clone of hmailserver.wiki:
#   python build/check-help-map.py --wiki <the clone> [--ref <its branch>]
#   python build/generate-help-pages.py
# The first holds every line to the wiki - its pages are exactly these, and each names the documents
# listed after it - and the second writes the two generated files.
#
# Checked against hmailserver.wiki at master 956183fada8a (5 October 2026) and main 0e084f7c24ab
# (27 September 2026, the branch GitLab shows), which hold the same 74 pages, on 15 October 2026.
